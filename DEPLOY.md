# BloodBridge — Live deployment

Live URLs:

- Frontend: `https://bloodbridge-app.riteshnethi-art.workers.dev` (Cloudflare Workers / Pages)
- Backend API: `https://bloodbridge-api-0m93.onrender.com` (Render free web service)
- API docs: `https://bloodbridge-api-0m93.onrender.com/docs`

Deployed 2026-10-28. Frontend deployed via `wrangler deploy` (static assets + SPA
fallback configured in `frontend/wrangler.jsonc`). Backend deployed from the
`render.yaml` Blueprint on the `riteshnethi-art/bloodbridge` GitHub repo.

## Architecture

| Piece | Where | Notes |
|---|---|---|
| React + Vite SPA | Cloudflare Pages | Unlimited bandwidth, free SSL, SPA fallback via `frontend/public/_redirects` |
| FastAPI backend | Render (free) | Sleeps after 15 min idle, ~1 min cold start |
| Database | SQLite on Render | Free plan has **no persistent disk** — DB re-seeds demo data on every deploy/restart. Swap `BLOODBRIDGE_DATABASE_URL` to a `postgresql+psycopg://...` URL for durable data (zero code changes needed). |

## Backend (Render)

Blueprint: `render.yaml` at the repo root (Render Dashboard → New → Blueprint →
select this repo). Key env vars (set in the Render dashboard → Environment, seeded by the
blueprint):

| Variable | Value |
|---|---|
| `BLOODBRIDGE_APP_BASE_URL` | `https://bloodbridge-app.riteshnethi-art.workers.dev` |
| `BLOODBRIDGE_EXTRA_CORS_ORIGINS` | `https://bloodbridge-app.riteshnethi-art.workers.dev` |
| `BLOODBRIDGE_AUTH_SECRET` | auto-generated by the blueprint (`generateValue: true`) |
| `BLOODBRIDGE_DATABASE_URL` | `sqlite:///./bloodbridge.db` |
| `BLOODBRIDGE_SEED_DEMO_DATA` | `true` |

Every push to GitHub is auto-deployed by Render.
Note: on the free plan the SQLite database is recreated with fresh demo data on
each redeploy; accounts/requests created through the live UI are lost on the
next deploy.

## Frontend (Cloudflare Workers)

Deployed with the new Workers-assets flow (config: `frontend/wrangler.jsonc`):

```powershell
cd frontend
$env:VITE_API_BASE_URL = "https://bloodbridge-api-0m93.onrender.com"
npm run build
npx wrangler deploy
```

`VITE_API_BASE_URL` is baked in at build time (see `src/api.ts`). Leave it unset
for local dev (same-origin proxy). Do not rebuild without setting it.

## Updating the site

1. Backend: `git push` — Render rebuilds. DB re-seeds (demo data returns).
2. Frontend: rebuild with the current `VITE_API_BASE_URL`, then
   `npx wrangler pages deploy dist`.

## Free-tier limits to remember

- Render free: 750 instance-hours/month per workspace, cold start ~1 min.
- Cloudflare Pages: unlimited static requests, unlimited bandwidth.
- Both are fine for demos and traffic spikes at this scale; upgrade only if
  persistence or always-on responses become a hard requirement.
